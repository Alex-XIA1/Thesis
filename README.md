# Thesis

Contains stuff regarding my experimentation for Vertex coloring problem :

- Different formulations such as; the assignment/natural MILP formulation, Palubeckis's formulation
- Some instances under the format DIMACS. These instances can be found on the vertex coloring benchmark (on the google website)
- Some julia code which are able to run these different formulation and some code that allow to visualize solutions or read DIMACS files.
